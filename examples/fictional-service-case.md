# Синтетический пример — сервис доставки уведомлений

> Все числа и названия вымышлены. Этот пример предназначен только для тестирования навыков.

## Входные данные
- TOP Objective: повысить надёжность клиентских коммуникаций.
- TOP KR: доля своевременно доставленных уведомлений ≥ 98% (вымышленный показатель).
- Руководитель направления: снизить задержки уведомлений в критических сценариях.
- Команда: 3 разработчика и 1 аналитик; baseline по задержкам пока не измерен.
- Коллеги: команда инфраструктуры отвечает за доступность очередей; команда каналов — за интеграции с SMS-провайдерами.
- Предлагаемый KR команды: «Для X% приоритетных сценариев доступна диагностика задержек до X минут».
- Квартальная инициатива: внедрить сбор и корреляцию идентификаторов сообщений в критических сценариях.

## Ожидаемые проверки
1. Не выдумывать baseline и X.
2. Разделить доступность очереди (другая команда) и скорость диагностики сообщения (наша команда).
3. Проверить причинную связь с своевременностью доставки; без прямых данных оставить CONDITIONAL.
4. Развести KR («какой результат») и инициативы («что делаем»).
5. Не обещать улучшения SLA внешнего SMS-провайдера без его обязательств.
6. Для каждой story сохранить ссылки на epic → initiative → KR.
