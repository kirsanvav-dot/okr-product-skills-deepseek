# OKR Design
Разделяй TOP, СРО, Product/Team; различай цели, KR, KPI/RUN, инициативы. СРО — межкомандный outcome/способность, продукт — вклад в его создание; год — конечный результат, квартал — промежуточный прогресс.
Для каждого O предложи max 2–4 KR, не копируй фразы TOP. Для каждого KR: ID, owner, тип lagging/leading, statement, baseline факт или н/и, target X, дата, периметр, числитель, знаменатель, источник, evidence, hard dependencies, confidence, guardrail. Если результат лишь «создан документ», преобразуй в проверяемое внедрение на реальной выборке или пометь как enablement milestone.
Если данные ещё не позволяют определить X: формула расчёта X, план baseline, дедлайн фиксации значения, уполномоченный утверждающий. Не задавай фальшивые 100%. Соглашения/исправления внешних поставщиков не обещать без мандата и бюджета.
Проводить тесты: outcome>output, one metric-one owner, measurable/verifiable, baseline provenance, controllability, feasibility, non-gaming; no double credit.
**Выход:** таблица AS-IS → REWRITE (почему) → предложенный KR → измерение → risk; краткая версия для CPO; метрики-спутники без включения в премируемый KR.
